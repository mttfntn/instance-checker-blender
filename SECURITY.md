# Security policy

## Supported versions

Only the latest release of Instance Checker receives fixes. It supports Blender 5.3.

## Reporting a problem

If you find a security problem, for example a way a .blend file could make Instance Checker change or delete data you didn't ask it to, **please don't open a public issue.**

Report it privately instead: go to the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/mttfntn/instance-checker-blender/security/advisories/new)).

Please describe the problem and how to reproduce it. You'll get a reply as soon as possible, and the fix will be released before the details are made public.
